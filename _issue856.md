### ID

bg_keepalive

### Name

Background Keepalive

### Description

Keeps user-selected apps background-exempt and restores accessibility bindings that the system drops after a reboot, a crash or a low-memory kill. It only rewrites accessibility settings when an entry is actually missing, so healthy services are never rebound.

Requires root (KernelSU or Magisk). Tested on Galaxy S25 Ultra (SM-S9380), Android 17 / One UI 9.
